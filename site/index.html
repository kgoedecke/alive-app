About Alive

Quit Alive⌘ Q

01

Automatic detection

Alive finds local Claude Code and Codex processes. There is nothing to start, name, or time.

02

Native power control

It uses macOS power-management APIs directly, with no Electron runtime or background web service.

03

Manual when needed

Override detection, choose whether the display stays on, and launch Alive at login.
